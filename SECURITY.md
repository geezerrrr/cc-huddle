# Security

openplan starts Claude Code sessions that edit files and run commands on your computer, under your Claude Code settings and the team's. A way around that, such as a member acting outside its rules without your answer, or your session's model answering for you, is a security issue.

Report one privately, through [GitHub's private vulnerability reporting](https://github.com/geezerrrr/openplan/security/advisories/new), not in a public issue. Say what you did, what happened, and the versions of openplan and Claude Code.

Only the latest release is supported.
